# RAG 技术基础

## 什么是 RAG

检索增强生成（Retrieval-Augmented Generation, RAG）是一种把外部知识库检索与大语言模型生成相结合的架构。它先根据用户问题从知识库中检索相关文档片段，再把片段作为上下文交给 LLM 生成答案，从而减少幻觉并支持回答私有数据问题。

## RAG 的主要环节

一个典型的 RAG 流水线包含四个环节：文档切分（Chunking）、向量化（Embedding）、检索（Retrieval）和生成（Generation）。文档切分把长文档切成适合检索的片段；向量化把文本映射到语义向量空间；检索阶段找出与问题最相关的片段；生成阶段由 LLM 基于检索结果组织答案。

## 混合检索与重排

仅靠向量检索（语义）可能漏掉词面匹配的片段，仅靠 BM25（词法）又难以处理同义改写。混合检索将两者结合，常用 Reciprocal Rank Fusion（RRF）融合排序。重排（Rerank）阶段用交叉编码器对候选片段精细打分，进一步提升精度。

## 如何评测 RAG 系统

评测 RAG 需要同时关注检索质量和答案质量。检索指标包括命中率（Hit Rate）、平均倒数排名（MRR）、精确率等；答案质量通常用 LLM 作为裁判评估忠实度（Faithfulness）和答案相关性（Answer Relevance）。
